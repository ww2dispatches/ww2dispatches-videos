# WW2 Dispatches videos

Living card videos, story videos, and the trimmed archival footage they were cut from, for WW2 Dispatches. Split off from ww2dispatches-cards on 18 Oct 2026 so the cards repo stays small.

* `videos/`: finished videos (dispatch-NNN-x.mp4, -instagram.mp4, -vertical.mp4, dispatch-NNN-story-am_onyx.mp4) and their poster frames.
* `footage/`: trimmed source clips used by renderer/living.js in the cards repo.

Buffer pulls videos from the raw links, for example https://raw.githubusercontent.com/ww2dispatches/ww2dispatches-videos/main/videos/dispatch-007-vertical.mp4, so never rename or delete a file that a scheduled post still uses. This repo can be cleared out or replaced later without touching the cards repo.
